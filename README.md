# Python Developer Portfolio

A personal developer portfolio built with Python and Flask to showcase my projects, technical skills, and development journey.

## 🚀 Features

- Responsive portfolio website
- Dynamic project listings using Flask and Jinja
- Individual project detail pages
- Contact form with server-side validation
- Custom 404 error page
- Responsive mobile layout
- Git and GitHub integration

## 💻 Running Locally

Clone the repository:

git clone https://github.com/meriemgfl/python-portfolio.git

Navigate into the project:

cd python-portfolio

Create a virtual environment:

python -m venv .venv

Activate the virtual environment on Windows:

.venv\Scripts\activate

Install the dependencies:

pip install flask

Run the application:

python app.py

Then open:

http://127.0.0.1:5000
